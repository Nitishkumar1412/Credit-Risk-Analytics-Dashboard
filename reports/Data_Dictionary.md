# Data Dictionary

## Project
End-to-End Credit Risk Analytics & Portfolio Optimization

---

| Column Name | Description |
|--------------|-------------|
| TARGET | Loan repayment status (0 = No Default, 1 = Default) |
| SK_ID_CURR | Unique ID of each loan application |
| NAME_CONTRACT_TYPE | Type of loan contract (Cash Loan or Revolving Loan) |
| CODE_GENDER | Gender of the applicant |
| FLAG_OWN_CAR | Whether the applicant owns a car |
| FLAG_OWN_REALTY | Whether the applicant owns a house/property |
| CNT_CHILDREN | Number of children |
| AMT_INCOME_TOTAL | Applicant's annual income |
| AMT_CREDIT | Total loan amount requested |
| AMT_ANNUITY | Loan repayment amount (installments) |
| AMT_GOODS_PRICE | Price of the purchased goods |
| NAME_INCOME_TYPE | Applicant's income source |
| NAME_EDUCATION_TYPE | Applicant's education level |
| NAME_FAMILY_STATUS | Marital status |
| NAME_HOUSING_TYPE | Type of housing |
| DAYS_BIRTH | Applicant's age (stored as negative days before application date) |
| DAYS_EMPLOYED | Number of days employed (negative values indicate days before the application date) |
| OCCUPATION_TYPE | Applicant's occupation |
| ORGANIZATION_TYPE | Employer organization type |
| EXT_SOURCE_1 | External credit score from source 1 |
| EXT_SOURCE_2 | External credit score from source 2 |
| EXT_SOURCE_3 | External credit score from source 3 |
